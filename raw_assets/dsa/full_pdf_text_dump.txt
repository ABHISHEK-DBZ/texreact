4. Singly Linked List
What it does: A chain of nodes where each node stores data  and a pointer next  to the
following node. head  points to the first node.
How it works
Insert at beginning: new node points to the old head, then becomes the head.
Insert at end: walk to the last node ( temp.next  is None) and attach the new node.
Delete at beginning: move head  to head.next .
Delete at end: walk until temp.next.next  is None, then cut the last node off
( temp.next = None ). A single-node list is handled separately.
Display: walk from head, printing each data .

5. Doubly Linked List
What it does: Like the singly linked list, but each node also has a prev  pointer to the node
before it, so links go both ways.
How it works
Insert at beginning: new node's next  = old head, old head's prev  = new node, then
update head .
Insert at end: walk to the last node, set temp.next = new_node  and new_node.prev =
temp .
Delete at beginning: move head  forward and clear the new head's prev .
Delete at end: walk to the last node and use temp.prev.next = None  (no need for the
next.next  trick).
Complexity: beginning operations O(1); end operations O(n) (no tail pointer is kept).

    def __init__(self, data):
        self.data = data

        self.next = None

def insert_beginning(value):
    global head
    new_node = Node(value)
    new_node.next = head

6. Insertion Sort
What it does: Sorts a list of numbers in ascending order.
How it works
Treat the left part of the array as already sorted.
Take the next element ( key ), shift every larger element in the sorted part one step
right, then drop key  into the gap.
Repeat for every element from index 1 to the end.
Complexity: O(n²) worst/average, O(n) best (already sorted). Stable and in-place.
arr = list(map(int, input("Enter array elements: ").split()))
for i in range(1, len(arr)):
    key = arr[i]
    j = i - 1
    while j >= 0 and arr[j] > key:
        arr[j + 1] = arr[j]
        j -= 1
    arr[j + 1] = key
print("Sorted array:", arr)

7. Binary Search Tree (BST)
What it does: Asks how many nodes you want, reads that many values, builds a Binary
Search Tree (smaller values go left, larger go right, duplicates are ignored), then prints the
tree sideways and its three traversals.
How it works
Insert: recursively go left or right until an empty spot is found, then create the node
there.
Display: visits right subtree, then the node, then left subtree, adding 5 spaces of
indentation at each level. This prints the tree rotated 90° – the root is at the left edge
and the right children appear on top.
Traversals:
Inorder (Left, Root, Right) → prints values in sorted order
Preorder (Root, Left, Right)
Postorder (Left, Right, Root)
Complexity: insert O(h) where h is the tree height – O(log n) when balanced, O(n) worst
case. Display and traversals O(n).
class Node:
    def __init__(self, data):
        self.data = data
        self.left = None
        self.right = None
def insert(root, value):
    if root is None:
        return Node(value)
    if value < root.data:
        root.left = insert(root.left, value)
    elif value > root.data:
        root.right = insert(root.right, value)
    return root
def display(root, space=0):
    if root is None:
        return
    space += 5
    display(root.right, space)
    print()
    print(" " * space + str(root.data))
    display(root.left, space)

8. Breadth First Search (BFS)
What it does: Builds an undirected graph from edges you enter, then visits vertices level
by level starting from a vertex you choose.
How it works
The graph is a dictionary (adjacency list): vertex → list of neighbours . add_edge
adds the link in both directions.
BFS uses a queue ( deque ) and a visited  set. Pop a vertex, print it, then add all
unvisited neighbours to the queue.

from collections import deque
graph = {}
def add_edge(u, v):
    if u not in graph:
        graph[u] = []
    if v not in graph:
        graph[v] = []
    graph[u].append(v)
    graph[v].append(u)
def bfs(start):
    visited = set()
    queue = deque([start])
    visited.add(start)
    while queue:
        vertex = queue.popleft()
        print(vertex, end=" ")
        for neighbour in graph.get(vertex, []):
            if neighbour not in visited:
                visited.add(neighbour)
                queue.append(neighbour)
    print()

9. Infix to Prefix Conversion (Using Stack)
What it does: Converts an expression like A+B*C  (infix) into prefix form +A*BC .
How it works
1. Reverse the expression and swap every (  with )  and vice-versa.
2. Scan left to right:
Letter/digit → append to result.
(  → push on stack.
)  → pop to the result until (  is found, then discard ( .
Operator → pop operators with higher precedence from the stack, then push the
current operator.
3. Pop whatever is left on the stack into the result.
4. Reverse the result to get the prefix expression.
Precedence used: ^  (3) > * / %  (2) > + -  (1).
Example: A+B*C  → +A*BC
Complexity: O(n).

def precedence(op):
    if op == '^':
        return 3
    elif op in '*/%':
        return 2
    elif op in '+-':
        return 1
    return 0
def infix_to_prefix(expression):
    expression = expression[::-1]
    expression = ''.join(')' if c == '(' else '(' if c == ')' else c
                         for c in expression)
    stack = []
    result = ""
    for char in expression:
        if char.isalnum():
            result += char
        elif char == '(':
            stack.append(char)
        elif char == ')':
            while stack and stack[-1] != '(':
                result += stack.pop()
            if stack:
                stack.pop()
        else:
            while (stack and stack[-1] != '(' and
                   precedence(stack[-1]) > precedence(char)):
                result += stack.pop()
            stack.append(char)
    while stack:
        result += stack.pop()
    return result[::-1]
expression = input("Enter infix expression: ")
print("Prefix expression:", infix_to_prefix(expression))
